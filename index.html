        Conectar ao GitHub

        As anotações são salvas como arquivos .md em um repositório seu. Recomendado: um repositório privado só para os dados.

        Um repositório público, separado do dos dados. As páginas marcadas como “🌐 Qualquer um vê” vão para ele e qualquer visitante do site pode lê-las. As marcadas como “🔒 Só eu vejo” continuam no repositório privado. Deixe vazio para ter só páginas privadas.

        Crie um token fine-grained com acesso só ao repositório dos dados (e ao das páginas públicas, se usar) e a permissão Contents: Read and write. O token fica guardado apenas neste navegador.
